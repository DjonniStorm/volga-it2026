# Волга-ИТ 2026: автоматизация тестирования

UI-тесты сайта [Practice Automation](https://practice-automation.com/) в рамках полуфинала «Автоматизация тестирования (Java, Python)».

## Стек

Python 3.12+, Selenium 4, Pytest, Allure Pytest. Page Object Model (`pages/`), независимые тесты (`tests/`), параметризация и явные ожидания.

## Запуск

Установить Chrome или Firefox и Python 3.12+. Selenium Manager автоматически подберёт драйвер при доступном интернете.

```bash
python -m venv .venv
pip install -r requirements.txt
pytest -v
allure serve allure-results
```

Для Windows активируйте окружение командой `.venv\Scripts\activate`, для Linux/macOS - `source .venv/bin/activate`.

По умолчанию используется headless Chrome. Для браузера с интерфейсом: `HEADLESS=0 pytest` (Linux/macOS) или `$env:HEADLESS="0"; pytest` (PowerShell). Для Firefox: `BROWSER=firefox pytest` или `$env:BROWSER="firefox"; pytest`.

## Отчёты и ошибки

`pytest` создаёт `allure-results/`; команда `allure serve allure-results` открывает интерактивный Allure-отчёт (нужен установленный Allure CLI). При ошибке автоматически прикладываются скриншот и HTML страницы.

## Примечания

Тесты выполняются на внешнем демонстрационном сайте; DOM и внешние ресурсы могут измениться. При изменениях сайта может потребоваться актуализировать локаторы. Параметризованные случаи в Pytest отображаются отдельно. Проверки Ads требуют доступности рекламного модального окна (не использовать блокировщик).
